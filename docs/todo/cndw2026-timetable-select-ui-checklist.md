# CNDW2026 タイムテーブルのセッション選択 UI 改善チェックリスト

## 背景
- セッションカードは、タイトルを押すと詳細モーダル、それ以外を押すと選択（参加登録）になっていた。
- 押せる場所の境界が見た目で分からず、詳細を見るつもりで選択してしまう、という声が多い。
- 現地参加者は時間が重なるセッションの選択が黙って外れるため、意図せず選択が入れ替わることがある。
- 選択はその場で確定せず、下部バーの「セッション登録」で確定する 2 段階であることも伝わりにくい。

## 方針
- PC・スマホで同じ見た目にする（ホバーで出し分けると lg 幅の iPad で操作できなくなるため）。
- カード本体のクリックは詳細モーダルを開く。選択は右上の「＋ 参加」ボタンだけで行う。

## タスク
- [x] カード全体を詳細モーダルのリンクにし、選択を専用の「＋ 参加 / ✓ 参加予定 / 満席」ボタンに分ける
- [x] 詳細モーダルに「このセッションに参加する」ボタンを追加する
- [x] 時間重複で他の選択を外したときにトーストで知らせる
- [x] 下部バーに選択件数と未登録の変更有無を表示する
- [x] 詳細モーダルを枠外クリック・Esc で閉じられるようにする
- [x] 詳細モーダルの × ボタンを Bootstrap 5 の `btn-close` にして右上に表示する（`.close` / `mr-auto` は Bootstrap 4 のクラスでスタイルが当たっていなかった）
- [x] request spec を更新する
- [x] rspec / rubocop を通す
- [x] ブラウザで表示確認（PC・スマホ幅・モーダル・トースト。ログイン状態は request spec と同じモックで生成した HTML を Playwright で確認）

## メモ
- Tailwind の preflight を無効にしているため `--tw-content` の既定値がなく、`after:` だけでは疑似要素が描画されない。
  カード全体のリンク（stretched link）には `after:tw-content-['']` を明示している。
